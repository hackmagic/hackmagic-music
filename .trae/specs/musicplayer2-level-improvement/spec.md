# HackMagic Music Player - 达到原版MusicPlayer2水平的改进PRD

## Overview
- **Summary**: 对当前的Rust+GPUI音乐播放器进行全面改进，使其功能和界面达到原版MusicPlayer2的水平
- **Purpose**: 解决当前版本存在的大量bug和功能缺失，提升用户体验和功能完整性
- **Target Users**: 音乐爱好者，需要完整功能的桌面音乐播放器用户

## Goals
- 修复核心播放功能的bug
- 完善界面和菜单功能，达到原版水平
- 实现缺失的核心功能（专辑封面、媒体库浏览、歌词显示等）
- 提升系统集成（全局快捷键、托盘、文件关联）
- 优化性能和稳定性

## Non-Goals (Out of Scope)
- 新增原版没有的功能
- 跨平台功能超出原版范围的部分（原版主要是Windows）
- 网络流媒体播放功能（YouTube等）
- 大规模重构核心架构

## Background & Context

当前项目是一个基于Rust+GPUI的音乐播放器，参考了MusicPlayer2（C++/Win32）的设计。项目已经实现了基本的播放功能，但存在以下问题：

1. **界面问题**: 迷你模式、全屏模式、专辑封面显示等功能不完善
2. **菜单问题**: 大量菜单项只是占位符，没有实际功能
3. **播放列表**: 拖拽排序、多选、收藏等功能缺失
4. **歌词**: 桌面歌词、翻译显示、延迟调整等功能不完善
5. **媒体库**: 分类浏览、统计等功能缺失
6. **设置**: 控件大多是静态的，没有实际交互
7. **系统集成**: 全局快捷键、托盘等功能不完善

原版MusicPlayer2的主要功能模块：
- 播放控制（播放/暂停/停止/前后切换/进度条）
- 播放列表（添加/删除/排序/搜索/重复模式）
- 媒体库（分类浏览/搜索/统计）
- 歌词（显示/编辑/下载/桌面歌词）
- 均衡器（10段均衡器/预设）
- 设置（外观/播放/歌词/快捷键等）
- 系统集成（全局快捷键/托盘/文件关联）
- 其他工具（格式转换/标签编辑/封面下载）

## Non-Functional Requirements

- **NFR-1**: 启动时间 < 2秒
- **NFR-2**: 播放列表响应时间 < 100ms
- **NFR-3**: 内存占用 < 100MB（空闲状态）
- **NFR-4**: CPU占用 < 5%（播放状态）
- **NFR-5**: 支持超过1000首歌曲的播放列表
- **NFR-6**: 支持中文文件名和标签
- **NFR-7**: 跨平台支持（Windows优先，Linux/macOS尽力而为）

## Constraints

- **Technical**: 
  - 使用Rust + GPUI框架
  - BASS引擎仅在Windows上可用，其他平台使用FFmpeg
  - GPUI框架的限制（部分UI功能可能需要自定义实现）
- **Business**: 保持与原版MusicPlayer2功能对齐
- **Dependencies**: BASS库（Windows）、FFmpeg、gpui、gpui-component

## Assumptions

- 用户主要在Windows上使用
- 用户需要完整的音乐播放器功能
- 用户希望界面美观且功能完整
- 网络连接可用（用于歌词下载、Last.fm等在线功能）

## Acceptance Criteria

### AC-1: 播放控制功能正常
- **Given**: 用户打开音乐文件
- **When**: 用户点击播放/暂停/停止按钮，拖动进度条，使用快退/快进
- **Then**: 播放器正确响应，进度条实时更新，播放状态正确切换
- **Verification**: `programmatic`

### AC-2: 播放列表功能完整
- **Given**: 播放列表中有多首歌曲
- **When**: 用户双击歌曲、拖拽排序、多选删除、收藏、搜索、排序
- **Then**: 所有操作正确执行，界面正确更新
- **Verification**: `programmatic`

### AC-3: 媒体库浏览功能
- **Given**: 媒体库已扫描
- **When**: 用户点击艺术家/专辑/流派等分类
- **Then**: 显示对应分类的歌曲列表，支持从媒体库添加到播放列表
- **Verification**: `human-judgment`

### AC-4: 歌词显示功能
- **Given**: 歌曲有对应的LRC歌词文件
- **When**: 用户播放歌曲
- **Then**: 歌词同步显示，支持卡拉OK风格，支持桌面歌词
- **Verification**: `human-judgment`

### AC-5: 菜单功能完整
- **Given**: 用户打开菜单
- **When**: 用户点击菜单项
- **Then**: 所有菜单项都有实际功能，不是占位符
- **Verification**: `human-judgment`

### AC-6: 设置功能可交互
- **Given**: 用户打开设置面板
- **When**: 用户修改设置项
- **Then**: 设置项可以修改，修改后立即生效或重启后生效
- **Verification**: `human-judgment`

### AC-7: 系统集成功能
- **Given**: 播放器正在运行
- **When**: 用户使用全局快捷键，查看系统托盘
- **Then**: 全局快捷键响应，托盘菜单显示正确
- **Verification**: `human-judgment`

### AC-8: 界面美观度
- **Given**: 用户打开播放器
- **When**: 用户查看界面
- **Then**: 界面美观，布局合理，响应流畅
- **Verification**: `human-judgment`

## 分析：HackMagic Music Player（Rust+GPUI）对照原版 MusicPlayer2

完成了对当前 Rust 重写实现（`src/`，25k 行）与原版 C++/MFC MusicPlayer2 的全面对比分析，产出报告 `docs/缺陷分析与改进计划.md`。

### 关键结论
- **编译通过**（仅 13 个 unused 警告）。音频双引擎（BASS + FFmpeg 兜底）在 `core/player.rs` 已完整实现；CLI 极其完整（`cli.rs` 1952 行）。
- **致命 bug B1**：GUI 无定时重绘驱动（`bin/gui.rs` 仅开窗口，无 `set_interval`/`cx.notify` 循环），`render()` 内 `poll_player_state` 只读状态但不触发重绘 → 播放时进度条/频谱/歌词冻结。这是最大坑，也是 GPUI 立即模式与原版自绘线程模型的核心差异。
- **装饰性均衡器 B2**：`render_equalizer_panel`(mod.rs:3146) 滑块只改本地字段，从不调 `player.eq_set`；曲线写死 `val=0.0`。引擎 `eq_set` 已实现但未接线。
- **专辑封面 B3**：主区是占位 `div()`，封面从未渲染（`tag::writer::read_pictures` 有但 GUI 未调用）。
- **深色/主题切换 B4**：存配置但不重绘，需重启。
- **死代码**：`src/gui/layout.rs` 的 `menu_bar`/`main_content` 是未接线的骨架（on_click 全空），与 `mod.rs` 真实 UI 重复。
- 菜单 7 项结构在 `render_menu_bar`(mod.rs:997)，File/Playback/Playlist/Tools 大部分连线；**Lyric 菜单几乎全 no-op**、歌词编辑器 9 按钮全"待实现"、View 的浮动播放列表/置顶/状态栏/深色重绘均无效。

### GPUI 可行性
原版全部 UI 能力在 GPUI 下均可实现（无根本障碍）；主要限制是必须手动驱动重绘、无原生菜单/加速表（需自己映射快捷键）、大列表需虚拟滚动、平台特定代码（托盘/SMTC/热键/置顶）Windows 已部分实现。

### 关键 GPUI 0.2.2 / gpui-component 0.5.1 坑（实测，纠正了之前的误判）
- **`gpui::Div` 不实现 `StatefulInteractiveElement`**（仅 `Img` 实现）。`Div` 滚动不能用 `overflow_y_scroll()`（该方法在该 trait 上，Div 没有）。正确做法：导入 `use gpui_component::scroll::ScrollableElement;`，用 `.overflow_y_scrollbar()` —— 它返回 `Scrollable<Div>` 但仍支持 `.py_1()`/`.children()` 等链式调用（Scrollable 实现了 Styled/ParentElement/IntoElement）。
- **`cx.listener` 闭包永远是 4 参 `(实体, 事件, window, cx)`**：`Fn(&mut T, &E, &mut Window, &mut Context<T>)`。实体(`this: &mut Self`)是**第1参**，事件(`&E`，如 `MouseButton`/`ClickEvent`)是**第2参**——不是 window！之前"on_click 用3参 `|this,window,cx|`"的判断是错的。例：`cx.listener(move |this: &mut MusicPlayer, _, _, _| {...})` 用于 `on_mouse_down`。
- **`Root::new(view, window, cx)` 的 `cx` 必须是 `&mut Context<Root>`**，不是 `&mut App`。在 `open_window` 闭包 `|window, cx|`（cx 是 `&mut App`）里须包一层：`cx.new(|cx| Root::new(view, window, cx))`。
- **`Button::new(id)` 的 `id: impl Into<ElementId>`**，`String` 不实现 `Into<ElementId>`。动态 id 用元组形式 `Button::new(("fp_track", i))`（`&'static str, usize` 已实现 `From`）或 `SharedString`。
- **`windows` 0.61 的 `SetWindowPos` 第2参 `hWndInsertAfter` 是 `Option<HWND>`**，须 `Some(HWND_TOPMOST)` / `Some(HWND::default())`。
- **`impl From<&LibEntry> for ViewEntry` 漏写 impl 块自身的闭合 `}`**（只有 fn 的 `}`，缺 impl 的 `}`）→ 之前在文件末尾误加了2个多余 `}` 导致 "unexpected closing delimiter"，删掉后反变 "unclosed delimiter"。正确修法是在 3931 行后补一个 `}` 关闭 impl。
- 分隔线用 `div().w(px(1.0)).h_full().bg(c.border)`（无 `border_right_1`/`border_left_1` API）。

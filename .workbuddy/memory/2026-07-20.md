## 分析：HackMagic Music Player（Rust+GPUI）对照原版 MusicPlayer2

完成了对当前 Rust 重写实现（`src/`，25k 行）与原版 C++/MFC MusicPlayer2 的全面对比分析，产出报告 `docs/缺陷分析与改进计划.md`。

### 关键结论
- **编译通过**（仅 13 个 unused 警告）。音频双引擎（BASS + FFmpeg 兜底）在 `core/player.rs` 已完整实现；CLI 极其完整（`cli.rs` 1952 行）。
- **致命 bug B1**：GUI 无定时重绘驱动（`bin/gui.rs` 仅开窗口，无 `set_interval`/`cx.notify` 循环），`render()` 内 `poll_player_state` 只读状态但不触发重绘 → 播放时进度条/频谱/歌词冻结。这是最大坑，也是 GPUI 立即模式与原版自绘线程模型的核心差异。
- **装饰性均衡器 B2**：`render_equalizer_panel`(mod.rs:3146) 滑块只改本地字段，从不调 `player.eq_set`；曲线写死 `val=0.0`。引擎 `eq_set` 已实现但未接线。
- **专辑封面 B3**：主区是占位 `div()`，封面从未渲染（`tag::writer::read_pictures` 有但 GUI 未调用）。
- **深色/主题切换 B4**：存配置但不重绘，需重启。
- **死代码**：`src/gui/layout.rs` 的 `menu_bar`/`main_content` 是未接线的骨架（on_click 全空），与 `mod.rs` 真实 UI 重复。
- 菜单 7 项结构在 `render_menu_bar`(mod.rs:997)，File/Playback/Playlist/Tools 大部分连线；**Lyric 菜单几乎全 no-op**、歌词编辑器 9 按钮全"待实现"、View 的浮动播放列表/置顶/状态栏/深色重绘均无效。

### GPUI 可行性
原版全部 UI 能力在 GPUI 下均可实现（无根本障碍）；主要限制是必须手动驱动重绘、无原生菜单/加速表（需自己映射快捷键）、大列表需虚拟滚动、平台特定代码（托盘/SMTC/热键/置顶）Windows 已部分实现。

## 实施：已完成的修复（Phase 0 + Phase 1）

用户确认"按此计划做修复和开发"。本 turn 完成并 `cargo build` 全量通过（无 error）。

### B1 重绘驱动（已修）— 最关键
- `src/gui/mod.rs` `MusicPlayer::new` 中新增 ~30fps 定时器：`cx.spawn(async move |this, cx| loop { background_executor().timer(33ms).await; this.update(cx, |_,cx| cx.notify()); })`。`this` 是 GPUI 提供的 `WeakEntity<MusicPlayer>`，窗口关闭后 `update` 返回 Err → break，自动停止。
- 关键 API 已查证（gpui 0.2.2）：`Context::spawn` 闭包签名 `(WeakEntity<T>, &mut AsyncApp)`；`AsyncApp::background_executor().timer(dur)`；`WeakEntity::update(cx, |_, cx| cx.notify())`。`render()` 内原有 NOTE 已更新说明重绘由定时器驱动。

### 死代码清理（已修）
- `src/gui/layout.rs` 删除未接线的 `menu_bar` + 7 个空子菜单、`main_content`、`icon_sidebar`、`sidebar_btn`、`control_bar`、`status_bar`。保留实际使用的 `txt`/`title_bar`/`menu_dropdown`/`content_area`(+deps)。注意 `dropdown_menu` 方法来自 `DropdownMenu` trait，必须 `use gpui_component::menu::DropdownMenu`。

### B2 均衡器接通引擎（已修）
- `eq_sliders` 改为命名局部变量并在 `new` 中为每个滑块 `cx.subscribe`：拖动时 `this.player.eq_set(i, v as i32)`（仅 enabled 时）。
- 启用开关 `on_click` 调 `player.eq_enable(...)`，启用时把各滑块值推给引擎、禁用时全置 0。
- 预设按钮应用：设置每个滑块 `set_value` 并（若 enabled）推引擎。
- 曲线预览改为读取真实滑块值（`slider.read(cx).value()`）。

### B3 专辑封面（已修）
- 新增 `album_art: Option<PathBuf>` 字段 + `extract_cover(file_path)` 方法：优先内嵌图（`tag::writer::read_pictures`）写临时文件，其次目录内 `cover/folder/album/front.*`。
- 在 `poll_player_state` 的换曲分支中调用，渲染用 `gpui::img(path)`（mini 模式 200px、控制栏 48px 缩略图），无封面回退灰色占位。

### B4 深色/主题实时重绘（已修）
- 原 `render_menu_bar` 新增 `let weak = _cx.entity().downgrade();`；深色/主题切换 `on_click`（原仅存配置）改为 `weak.update(cx, |this, cx| { this.colours = UiColors::build(dark, &theme); cx.notify(); })` → 无需重启即生效。
